# Version 2.1.0 store captures

Order: **Home → Card → Benefits → Events** in every directory.

- `ios-6.9`: 1320 × 2868 PNG, four images.
- `ipad-13`: 2064 × 2752 PNG, four images.
- `play-phone`: 1179 × 2556 PNG, four images.

These are captures of the current React Native web UI export from the final platform/sign-out verification,
using the same runtime/shared source as iOS build 25 and Android version code 31. They use isolated, illustrative
Aurora Members Club fixtures. They are **UI-render captures, not physical-device or simulator screenshots**.
No AI-generated app screens, composite phone frames, real customer data or reviewer credentials are included.
The sample QR encodes an explicitly non-production demo URL; it cannot authenticate a real membership.

Capture routes are loaded directly, with fonts, data and visible content settled before capturing, to avoid
sampling a navigation transition. The copy and feature controls are the current app's own components.

The owner's separate physical iPhone recording is `loyalty.mp4` in the original project's root. It is attached
to App Review privately and is not committed. Device details supplied by the owner: iPhone 13, iOS 18.7.
It is a 19.38-second signed-in walkthrough; launch, registration, login and deletion are not demonstrated.
App Review notes disclose those limitations and the absence of physical iPad QA.

Historical captures outside this version directory show the older booking UI and must not be reused for 2.1.
