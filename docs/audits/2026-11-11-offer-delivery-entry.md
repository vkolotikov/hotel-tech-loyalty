The user could not find where to attach a voucher and send it to selected or all members. Offers now exposes **Attach & send** in the saved-offer heading and in the sticky create/edit footer. The editor validates and saves before opening a single attachment and delivery popup. Upload/replace/remove, selected-member search, an all-eligible option and the reviewed channel counts are together in the existing staff design. The review scrolls into view before confirmation; phone footer actions wrap. All new copy ships in five languages.

All-member preview resolves active, eligible own members with the existing 5,000-target cap. Private offers remain restricted to their saved recipients and tiers keep their eligibility. Preview returns exact IDs; final send uses that frozen cohort through the existing idempotent outbox, canonical campaign pipeline and portal writer. Later enrolments cannot join an already reviewed send. Saving, uploading and previewing never deliver anything. Consent, suppression and portal-message preferences continue to apply. File changes reset review and file metadata participates in the revision.
