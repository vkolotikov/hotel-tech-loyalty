# Loyalty guide refresh

The staff Help & guide now starts with four expandable, numbered task guides: voucher delivery, Events, programme setup and member portal support. Each explains the actual current screens and links to the relevant page when the staff member has the management permission. Search includes the task instructions and automatically opens matches; an announced result count and reset action support recovery. The scan practice demo, quick start, feature index and existing FAQs remain available.

New FAQs explain file delivery, eligibility versus delivery recipients, and channel exclusions. Existing feature names, event instructions and portal information are updated. All content is translated into English, German, Spanish, French and Russian. Existing loyalty navy/Poppins tokens are retained. Decorative floating icons are removed; native details provide keyboard interaction without new dependencies or stored completion claims. Guide search padding is scoped explicitly to keep the icon clear.

Validation and release receipt will be recorded after the artifact checks and live verification.
