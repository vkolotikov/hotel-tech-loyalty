# HotelTech templates

1. **Maison Lume** — intimate old-city townhouse hotel.
2. **Northline Retreat** — Nordic lakeside retreat and sauna stay.
3. **Orbit City** — premium smart city hotel.

Each template is a standalone, no-JavaScript landing page. Primary calls to action open the host booking widget. Footers combine booking, guest reviews, contacts, social SVG icons and a transparent reserved AI-widget slot.
