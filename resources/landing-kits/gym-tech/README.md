# GymTech templates

1. **Aera Reformer** — warm boutique Pilates and movement coaching.
2. **Foundry Strength** — private strength and personal training club.
3. **Tempo Studio** — premium tech-led group strength and conditioning.

Each template is a standalone no-JavaScript landing page. All primary calls to action are booking hooks for the host booking widget. Footers contain booking, reviews, contact details, social SVG icons and an invisible reserved AI-widget slot.
