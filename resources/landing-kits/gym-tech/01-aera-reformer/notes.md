# Aera Reformer

Warm editorial template for a boutique reformer Pilates studio. Booking links use `data-action="open-booking"`; review links use `data-action="open-feedback"`. The empty `data-ai-widget-slot` at the right edge of the footer is reserved for the host AI widget and intentionally has no visible container styling.

Generated assets: `hero-reformer.webp` and `coached-movement.webp`.
